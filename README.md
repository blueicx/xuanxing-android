一款**离线优先**的玄学与自我探索 App，涵盖东方命理、西方占星、世界多元占卜与性格测试。
所有推算与解读均在**设备本地完成，无需联网**，也不收集任何个人数据。

> 项目早期曾用名「玄机」，包名保留为 `com.xuanji.app`。

## 功能概览

- **综合 / 东方（五行八字）**
  - 由出生时间推算八字四柱（节气采用经验表，结果明确标注为离线近似）
  - 五行分布可视化（金木水火土，缺项高亮）、日主、生肖、喜用神
  - 每日运势：综合 / 事业 / 财运 / 感情 / 健康 五维评分 + 今日干支 + 幸运色 / 方位 + 建议
  - 日 / 周 / 月 / 年沿用各自已计算的周期结果；运势板块可进入完整详情并携带当前结果和依据询问玄师，不把今日详情误送到一生命盘
  - 今日行动：用五行喜用、太阳星座、当日综合盘面和季节/手动城市标签计算具体菜名、行动时段和出游环境；固定权重、离线可复算，同分只做稳定排序
  - 详情可加入安排并编辑时间、备注和用餐份数；周餐单整理主动保存的餐食。预算按保存时每份目录估价乘份数，明确为参考；库存按名称核对，不虚构食材克数或营养数据
- **西方（星座）**
  - 由出生月日判定星座、属性、日期范围、性格特质
  - 每日运势：五维评分 + 幸运数字 / 颜色 / 方位 + 当日寄语
- **占卜（世界多元体系）**
  - 顶级板块：亚洲 / 非洲 / 欧洲 / 美洲 / 近现代新兴 / 常用占卜
  - 含紫微斗数（中州 / 北 / 闽三派合一）、奇门、风水、六爻、易经、塔罗、水晶球、灵签抽签等数十个体系
  - 全手绘专属图标 + 摇签 / 翻书 / 贝壳旋转等动态效果
  - 塔罗支持随机抽牌与按档案、日期、问题、牌阵稳定复现（单张 / 三张 / 五张）；卢恩支持单符 / 三符；数字命理增加个人年 / 月 / 日周期与计算步骤
- **测试（性格 · 职业 · 趣味）**
  - MBTI、大五人格、卡特尔 16PF、MMPI、霍兰德 RIASEC、霍格沃兹学院
  - 趣味合集：九型人格 / DISC / 性格色彩 / 菲尔人格 / 颜色心理 / 瑞文智力 / 动物 · 美食 · 影视 · 颜色等
  - 确定性计分，本地保存测试记录
- **历史 · 同月同日生 · 我的收藏**：保留历史与同日生内容；用户主动收藏的运势详情、行动、玄师回复和游戏摘要可在本机按类型筛选、搜索、回看与删除；「近期选择」只汇总显式收藏与行动反馈，不读取聊天或推断人格
- **人物交流 · 四位玄师来客 · 中国象棋**：在综合/东方/西方页的对话面板中与四位角色交流并真实对弈中国象棋
  - 四位独立来客：沈砚舟（江南书生）、墨衡（灰发水墨老法师）、伊芙琳·诺瓦（学院星象师）、纳迪尔·拉希德（丝路占星师）
  - 全屏 Horizontal Pager 画廊可左右切换；每位角色有独立对话线程、专长入口、交接语和棋盘材质，盘面事实与用户主动记忆共享；线程可从 DataStore 恢复并按角色清除
  - 四位角色共用统一五层全屏舞台（场景底板 / 遮罩 / 人物 / 顶部信息 / 底部陪伴抽屉）；江南水榭、水墨案头、学院观测台、丝路驿站各有独立道具和光色，墨衡不再是无背景例外；图片缺失时回退到本地 Canvas 与水墨静室
  - 纯 Kotlin 规则核心：合法走法、吃子、将军/将死/困毙、三次重复与限着判和，全部本地校验
  - 本地 alpha-beta 搜索引擎（难度=2/3/4 层），走子后自动应手；不显示胜率/等级分
  - 角色解说只引用真实棋盘事件（棋子/坐标/吃子/胜负），不结合运势下结论
  - 角色游戏：沈砚舟的诗句接龙、墨衡的中国象棋、伊芙琳的星图观测、纳迪尔的丝路路线规划；均为本地确定性互动，围棋与国际象棋仍明确未启用
  - 对话可直接说「换个难度」「观战」「有哪些威胁」「来局残局」「重做」「保存棋局」「继续棋局」「战绩」
  - 续局存档与战绩落 DataStore（按档案指纹分仓），只存局面与棋谱，角色评语不入库
  - 棋盘 9×10 可点选走子，系统动画时长缩放为 0 时自动跳过落子滑动动画，控件 ≥48dp 并带 TalkBack 描述
  - 围棋与国际象棋仅预留接口，明确显示「尚未启用」而不伪造棋盘
  - 深陪伴对话默认离线：支持主题/实体分析、连续追问澄清、可编辑/撤回的本地软标签；新推断标签默认 30 天，隐私页可保留原期限、选择 7/30/90 天或无期限，过期仅留在管理页。用户编辑/撤回不被后续推断覆盖；在线 Provider 只保留显式扩展接缝
  - 舞台对话抽屉默认收起，点击后展开消息、今日行动、依据和游戏；沈砚舟/伊芙琳/纳迪尔使用完整文化场景图，墨衡使用透明人物叠加水墨背景，避免重复背景
  - 诗句接龙、星图观测和丝路路线按档案/角色/游戏分别保存进度；诗句/星图提供固定关卡、提示与撤销，丝路提供按路段资源重算的撤销和路线回放；重开只清除当前游戏，生成文案不进入游戏存档
  - 对话中的“还剩几天 / 多少补给 / 下一站怎么选 / 继续游戏”读取当前角色的本机有效存档；没有有效存档时明确说明，不会悄悄新开一局
  - 游戏进度依据单独标为“本机存档”，不混入今日运势权重；游戏结束后只有用户主动点“收藏本局摘要”才写入本地收藏
  - 舞台标题显示当前角色姓名；「玄学家 / 半仙」仅作为内部语气模式，文化场景、道具、动作和语汇不宣称为真实仪式
  - 角色语气适配器会按意图选择专长并在回答前后加来源边界；依据层展示算法版本、seed、权重、置信度和缺失输入
- **我的 · 命盘设置**：出生日期 / 时间 / 地点编辑并保存（DataStore 本地存储）
  - 一生命盘独立提供人生概览、东方本命与西方本命入口；人生画像显示职业倾向簇、色彩灵感、环境类型和最多 3 个国家/城市匹配示例，缺失输入会注明
  - 资料完整度：逐项显示出生日期、时间、地点、坐标与性别是否已保存及其用途；只提示缺项，不改变算法分数、不猜测缺失资料
  - 饮食偏好：素食、清真、忌辣、忌酒和自定义排除项只保存在本机并按档案隔离
  - 活动偏好：用户可明确选择精力强度、室内优先和最长时长，按档案本地保存并用于筛选今日活动，不从聊天或行为推断偏好
  - 今日行动约束：过敏原、单餐预算、准备时长；卡片支持换一个、采纳或标记不合适，用户主动反馈可影响同类别候选次序并可撤销
  - 天气与地点（可选）：手动城市搜索、Open-Meteo 实时天气、调用手机地图；默认关闭联网且不读取 GPS
  - 选择性本地备份：默认使用 AES-GCM + PBKDF2 密码加密（密码至少 12 位且不保存）；可勾选收藏、行动反馈、小游戏进度、象棋棋谱、偏好、安排/库存、备注及快照。v4 保留餐食份数与预算参考，兼容 v1–v3；恢复前预览并确认冲突，备注未选时保留本机备注。备份不含出生资料、聊天、长期记忆或象棋战绩；明文 SHA-256 只校验完整性
- **提醒**：默认关闭，主动开启后由 WorkManager 调度运势或安排通知；安排通知可直接标记当前事项完成或约一小时后再提醒，系统省电可能造成延迟
- 深色神秘主题（紫 + 流金），Material 3，沉浸式状态栏 / 导航栏

## 技术栈

- Kotlin + Jetpack Compose（Material 3）
- MVVM（ViewModel + StateFlow）+ 单向数据流
- DataStore（Preferences）做离线存储与每日运势缓存（按日期 + 命盘指纹缓存，结果稳定）
- WorkManager 每日提醒
- 最低 SDK 26（Android 8.0），目标 / 编译 SDK 34
- Compose BOM 2024.02.00，Kotlin 1.9.22，Compose 编译器 1.5.10

## 如何运行

需要用 **Android Studio（Hedgehog 或更新版本）** 打开本项目并运行。

1. 安装 [Android Studio](https://developer.android.com/studio) 与 Android SDK（API 34）。
2. 打开 Android Studio → `File / Open` → 选择 `xuanji-android` 目录。
3. 首次打开会触发 Gradle 同步（已内置 Gradle Wrapper，无需本机预装 Gradle）。
4. 连接安卓设备或启动模拟器（API 26+）。
5. 点击 ▶ Run，或执行 `./gradlew assembleDebug`（Windows 用 `gradlew.bat`）。

> 应用默认离线运行，无需 API Key 或后端服务；天气/城市联网是可选扩展，失败会回退离线目录。

今日行动与人生画像是文化/生活方式灵感，不构成医疗、过敏、营养治疗、心理诊断、投资、移民、旅行安全或收入建议。城市默认采用离线静态标签；只有用户在“我的 → 隐私与数据”显式开启并手动搜索时，才会请求天气/地理编码，且不请求 GPS。在线 Provider 不能覆盖本地盘面事实或安全边界。

历法与测验数据边界：农历/闰月采用 1900–2100 表驱动换算；Ifá 256 组合、纳迪叶文和心理测验均遵循来源与授权标记，默认离线，不伪造经文、叶文或商业量表常模。

棋局边界：中国象棋规则与本地 alpha-beta 搜索完全离线运行，续局存档与战绩只存本机 DataStore；角色话术只基于棋盘事实。Pikafish 原生引擎、围棋 GTP、国际象棋 UCI 均为预留接口，未打包二进制、不联网；接入前需完成对应开源许可（GPLv3 等）与 source offer（见 `NOTICE-THIRD-PARTY.md` 与 `docs/BOARD_GAME_INTEGRATION.md`）。

## 自动构建（CI）

每次 push 到 `main` 或发起 PR 时，[GitHub Actions](https://github.com/blueicx/xuanxing-android/actions) 会自动执行 `.github/workflows/build.yml`：安装 JDK 17 + Android SDK 34、构建并上传 debug APK。构建产物 `xuanxing-debug-apk` 可在对应 Actions 任务页下载（保留 30 天）。

## 隐私

本应用默认**不联网、不上传、不收集**任何用户数据。天气/城市扩展只有在用户明确开启、手动输入城市并点击请求时才访问公开接口；不读取 GPS、不上传出生档案，联网开关与缓存可随时撤回和清除。命盘、运势、占卜与测试结果仍在本地计算并仅存储于本机 DataStore。
