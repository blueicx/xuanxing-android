# X3 深陪伴扩展与安全联网设计

## 目标

在保持离线默认、确定性算法和现有体验的前提下，完成以下扩展：

1. 将已有塔罗、卢恩、数字命理从“随机展示”扩展为可复现牌阵/周期/计算依据，并提供本地历史记录。
2. 让“今日行动”可以根据五行、星座、综合盘面、季节、城市和已确认的饮食约束，给出具体食物、活动与地点类型，并允许反馈。
3. 增加显式同意的天气/地点联网 seam：默认不联网、不读定位；用户手动选择城市后才请求天气。
4. 对话可路由到上述模块，先给核心答案，再给可解释入口；旧请求、跨主题和错误 provider 结果不能污染当前会话。
5. 健康、投资和人格内容严格边界化：健康只做症状记录/一般信息提示，投资只做数据与风险维度展示，人格结果只来自用户主动完成的测验，不从聊天隐式推断。

## 不在本轮做的事

- 不接入具体大模型厂商，不写入任何密钥。
- 不提供诊断、处方、剂量、个体化治疗方案，不输出买卖/收益承诺。
- 不默认读取 GPS；不自动上传出生信息、聊天、软标签或测试结果。
- 不把“占卜分数”描述成现实世界的因果或确定预测。

## 领域契约

### 可复现占卜

所有抽牌/抽符文/周期计算接受 `DivinationQuery`（profile、date、question、spread），使用 SHA-256 派生种子。相同输入必须得到相同结果；“随机抽取”仍保留用户主动重新抽取的操作。结果包含算法版本、输入摘要、解释和免责声明，历史只保存本机已确认的结果。

### 今日行动

`DailyActionPlanner` 继续使用五行 40%、星座 25%、今日盘面 20%、季节/城市 15% 的权重。新增时间、预算、能量和过敏/忌口过滤；过滤后为空时展示“没有满足条件的目录候选”，不伪造菜名。只有日周期渲染行动卡，周/月/年不显示。

### 外部上下文

`ExternalContextProvider` 包含离线城市目录和可选的 Open-Meteo provider。网络开关、手动城市和隐私同意均由用户控制；请求失败回退到缓存/离线城市标签。位置权限不是必需项。

### 安全护栏

所有对话和 provider 文本经过本地 `SafetyResponseGuard`：

- 健康结论式问题转为风险提示和就医建议入口；不回答诊断、用药或剂量。
- 投资结论式问题转为信息、波动和风险清单；不回答买入、卖出、仓位或收益保证。
- 人格/敏感属性必须标记 `ExplicitAssessment`，聊天内容只能标记 `Unknown`。

## UI 约定

- 综合页只展示合参结论；东方/西方页展示各自体系。
- 今日行动卡支持“为什么、换一个、已采纳/不合适”反馈，保存到本机。
- 画像页展示证据、缺失输入和可调整优先级；地区结果是“匹配示例”，不是迁移/签证建议。
- 占卜页显示牌阵、算法版本、可复现输入摘要和历史入口。
- 联网开关与数据清除入口位于“我的 → 隐私与数据”。

## 验收

- JVM 测试覆盖确定性、过滤、缓存回退、安全拦截、人格来源和对话路由。
- Android gates：`:app:testDebugUnitTest`、`:app:lintDebug`、`:app:assembleDebug`。
- 没有手机复测授权前，不执行安装、截图、TalkBack 或 Logcat 验收。
