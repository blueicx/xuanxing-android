# X3 稳定可信与本地回顾扩充规格

## 目标

在既有离线功能上完成五项收口：真实交互回归、100 条以上对话相关性评测、本地回顾时间线、可预览校验的选择性备份恢复、三款陪伴游戏的撤销/关卡/回放。保持用户已确认的运势内容、首页布局和既有视觉语言。

## 范围与用户数据边界

- 只在合成资料和隔离测试存储上验证 Compose 交互；允许 API 34 模拟器或 CI，禁止把 Gradle 测试部署到用户手机。此轮不做视觉、大字号、TalkBack 或人工无障碍验收。
- 对话评测集使用项目自拟样例，不收集、导入或上传真实用户消息。每个案例验证稳定意图、实体/路由结果以及无资料时的诚实回退；健康与财务边界继续由现有安全守卫承担。
- 回顾时间线只汇总用户主动收藏的结果/终局摘要与用户明确提交的行动反馈。自动保存的中途棋局不自动变成回顾记录；不推断人格、偏好或运势准确度。
- 备份分项选择收藏、行动反馈和游戏进度（包含角色小游戏当前档与象棋棋谱，不包含象棋战绩）；不默认包含出生档案、聊天线程或长期记忆。导入前展示版本、档案指纹、校验结果、各项数量和冲突；只有用户确认后写入。收藏/反馈按 ID 幂等合并；游戏冲突需明确选择覆盖当前同角色同游戏存档。
- 诗句与星图关卡使用自有短句和逻辑图，不冒充传统文本或占星结论。丝路游戏保持离线与示意路线边界，不添加未经核验的城市经纬度。

## 架构

1. **对话回归：** 一份版本化 JSON 测试资源作为 Kotlin JVM 与 Node 契约的共同数据源，至少 100 条、四角色均衡覆盖。JVM 测试调用真实分类器/分析器/路由器/离线回复及安全校验；只输出本地汇总。
2. **本地回顾：** 新增纯 Kotlin 时间线项与排序/过滤规则，由 Repository 合并 `ReadingFavoriteStore` 和 `ActionFeedbackDataStore` 数据。游戏摘要沿用已主动收藏的快照。记录页增加紧凑分段，不增加首页卡片。
3. **备份恢复：** 新增版本化 DTO、规范化编码和 SHA-256 校验；独立协调器读取/写入现有 profile 隔离 stores。Android UI 用系统文档选择器读取/写入 JSON，预览及显式确认前不改变任何 store。
4. **游戏：** 在现有纯 Kotlin engines 上增加 undo、提示/关卡推进及结果回放；丝路撤销从已记录路径重算日数/补给。升级游戏进度 envelope 并迁移旧档，不改变中国象棋规则与现有章节。
5. **运行验证：** 扩展现有 Compose 交互用例与 API 34 模拟器 workflow；只使用合成资料、测试 profile 和测试应用沙箱。若本地隔离模拟器不可用，明确以 CI 作为运行门禁，不能把 AndroidTest 编译当作交互运行。

## 验收

- 对话 JSON 至少 100 个唯一案例，四角色都有覆盖，分类/路由/安全边界由实际 Kotlin 实现执行；契约脚本验证数据完整性。
- 回顾时间线排序、筛选、空态、重复项和 profile 隔离有 JVM/repository/Compose 测试。
- 备份选择集、编码/解码、校验失败、档案不匹配、损坏/不支持版本、幂等合并及游戏冲突确认有测试；未确认时 store 内容完全不变。
- 三款游戏的 undo、level/progression、restart、replay summary、持久化恢复和旧版本状态迁移有测试。
- `node` 全部契约、`:app:testDebugUnitTest`、`:app:lintDebug`、`:app:assembleDebug`、`:app:assembleDebugAndroidTest` 和隔离模拟器 `connectedDebugAndroidTest` 通过；设备不可用时如实注明运行门禁未闭环。
- README、系统概览、技术债与本轮交接记录同步；不提交或推送。
