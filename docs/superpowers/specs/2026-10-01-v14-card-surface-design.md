# v14 卡片表面语言统一规格

## 目标

修正玄星页面卡片像来自不同组件库的问题。统一卡片的材质、描边、圆角、阴影和间距，同时保留 v14 原型规定的趋势、饮食、行动、出行语义色；不改运算、文案、板块顺序或详情内容。

## 视觉规则

| 角色 | 填充与描边 | 形状与层级 |
| --- | --- | --- |
| 普通内容卡 | `#251D34` 填充，`#382F4A` 细描边 | 12dp 圆角、约 10dp 内边距、无凸起阴影 |
| 紧凑维度卡 | `#29213A` 填充，`#342A48` 描边 | 10–11dp 圆角；卡间距与普通卡一致 |
| 趋势主视觉 | 径向渐变 `#674B90 → #35274D → #282039` | 17dp 圆角；这是唯一大面积紫色渐变主卡 |
| 饮食行动卡 | 暖色渐变 `#4A3151 → #2D213E → #4D3A26`，`#83644D` 描边 | 15dp 圆角；只在食物图标、标题和轻微暖色表面强调饮食 |
| 活动 / 出行行动卡 | 深色渐变 `#28213B → #211B2E`；活动描边 `#476363`，出行描边 `#705F3B` | 13dp 圆角；同一尺寸、间距、描边粗细，类别色只作轻强调 |

## 应用范围

- `FortuneCard` 采用普通内容卡 token，覆盖综合、东方、西方及复用该组件的结果详情卡。
- 趋势卡、六维卡、摘要标签、三类今日行动卡使用各自语义 token；它们共享一致的边线质感、文字间距和按压可点击结构。
- 标题、结果、评分、依据、详情页入口和反馈行为保持当前语义；只调整视觉表面。
- 不添加新依赖、不引入额外动画、不修改系统字体或用户数据。

## 验收

- 来源契约验证普通卡、趋势卡、紧凑卡和行动卡均引用集中定义的 token，阻止重新散落硬编码颜色/圆角。
- Node v14 shell contract、JVM 单测、Android `lintDebug`、`assembleDebug` 和 `assembleDebugAndroidTest` 通过。
- 在原连接 Xperia XZ2 上保留应用数据覆盖安装，查看综合/东方/西方页及一张详情页；截图确认卡片边界一致、语义色克制、文字不溢出，并检查进程与崩溃日志。
