# 同日生内容与 B+C 文化角色交流设计

## 目标

改善三个已验证问题：同年同月同日生页面被长评语占满、内容缺少音乐/诗歌入口、人物文化差异看起来只是换色且对话偶尔答非所问。本轮不改变离线默认、不接入在线模型，也不启动手机复测。

## 1. 同日生内容结构

`SameDayBirth.Figure` 保留人物基本字段，新增可选作品类型与作品元数据模型。历史页在每位人物卡下增加“今日的声音与诗”卡：

- 音乐：标题、作者/作曲家、年代、风格与一句聆听提示。
- 诗歌：公版作品可显示短摘录（不超过应用自有短文范围），仍在版权期的作品只显示标题、作者、年代与风格。
- 作品条目按月日确定性选择，不使用随机数；无匹配时回退到内置公版条目。

人物评语默认只显示摘要（最多两行或固定高度），使用 `AnimatedVisibility`/可访问的 `TextButton` 展开全文；折叠状态按页面会话保存，旋转后不丢失。

## 2. B+C 角色视觉方案

继续共享慈翁/魔师的脸部和身体基础，文化差异由两层表达：

1. 文化道具层（B）：每个皮肤至少有一个非颜色识别物，如交领/经卷、学院翻领/徽章、丝路披肩/串珠、沙漠头巾/腰带、节庆鼓饰/乐器。
2. 场景层（C）：舞台背景提供低对比度环境线索（书斋、星盘台、沙漠夜营、鼓乐祭台），不覆盖脸部、对话和关闭按钮。

道具与场景使用 `skinId` 的稳定映射；不同文化不能只修改 `garment`/`trim` 颜色。移动端保持单 Canvas、有限图层和 reduced-motion 兼容。

## 3. 对话承接与安全

在 `MysticIntentClassifier` 之后增加上下文承接选择：当前输入优先，若为闲聊/情绪表达则先回应该意图，再根据最近一轮主题提供一个可选转运势句；连续追问沿用最近主题，明确换题后清空承接。健康/财务输入继续只给一般性提醒，不给诊断、收益或买卖结论。

对话回复必须包含与用户输入对应的关键词或承接句，避免直接返回无关的固定评语；确定性 seed 仍由 profile/date/mode/style/skin/topic/input 组成。

## 4. 验收

- 同日生页默认折叠，点击后可展开并再次折叠；音乐/诗歌卡可见，公版/非公版展示规则正确。
- B+C 皮肤在截图中能通过轮廓/道具/场景区分，不遮挡正文和关闭按钮。
- “你好”“谢谢”“我很焦虑”“最近工作怎么样”“换个话题后问运势”等输入先答所问；健康/财务边界不越界。
- Android 单测、lint、assemble 通过；手机复测由用户另行通知后执行。
