# X3 1.1.2 日常与陪伴深化收口

本轮保持单代理、默认离线、用户主动记忆；保留现有文件和设备数据。Debug 1.1.2（4），不是正式签名 Release。人工视觉、大字号及 TalkBack 不在本轮范围。

## 功能入口

- 详情中的「探索计算步骤、相邻周期与时辰敏感性」：实际计算上一/当前/下一周期；综合六维步骤与生成器共用实现，移除统一 50:50 的错误依据。八字 ±60 分钟只重新计算四柱，不校正出生资料、不外推到其他体系。旧快照不被覆盖。
- 九个答题界面（含三组趣味子测验）共用按档案隔离的本机草稿和计分前复核。可以直接修改已答题，不丢后续答案；损坏、版本不兼容或写入失败明确提示。草稿不进入备份、搜索或长期记忆。
- 新测验历史按档案保存原始/项目分，同测验同版本才比较数值；最多 100 条，满额拒绝而不是静默删旧。旧版无归属记录单独只读保留，不擅自迁移。玄师只可引用用户逐条授权的那一份结果摘要，授权绑定实际分数与版本，可以撤回。
- 隐私页可独立清除草稿、历史、授权；清除历史同时撤回授权。保存票据及完整清除写入栅栏阻止旧异步结果重新写回新测验存储。出生、聊天与长期记忆仍不进入既有选择性备份。
- 用户主动打开的卡片可成为未完成角色任务；可以继续、完成、移除和交接，保留原日期与内容，不伪装成跨日新结果。角色独立线程及旧 token 丢弃沿用真实 reducer；会话协议 v3 兼容 v1/v2，不恢复已失效请求。
- 诗句可试写下句并核对字数；明确不判断平仄、词性或严格古典对仗。星图按实际图和当前位置计算最短路径；象棋对当前/回放局面的合法着法提供逐步规则演练，不证明多步必胜、不代走。丝路保留 12 任务与真实资源回放，并显示本地坐标来源和自编游戏边界。旧游戏进度格式和分数没有重写。
- 综合首页五个板块支持上移、下移、置顶、恢复默认；不删减原内容或改卡片设计。今日行动仍不出现在周/月/年。详情阅读位置按档案和具体结果保存。
- 桌面「日常快捷入口」提供我的安排和继续玄师/游戏；不把个人安排或聊天发布在桌面。安排快捷入口将实际日历放在历史内容之前；玄师入口等本地角色检查点加载后召回对应舞台，不自动新开棋局。
- 分享先选择实际字段和预览再打开系统分享；未选字段不附带。图片按选中全文测量高度，不再静默只取前三行；超限报错。文件流和位图均释放，仅失败时删除该次生成的不完整文件。

## 已知边界

没有新增正式心理量表授权或人口常模，没有联网模型、导航或新的传统经文；没有医疗、投资或人格诊断结论。星图是自编逻辑图，诗句为自有短句，丝路不是历史路网或现实旅行建议。

当前仍为 Debug 签名；不生成或提交正式密钥。桌面快捷入口测试不等于不同厂商启动器的人工适配验收；系统分享选择器、第三方日历导入和系统省电下的长期提醒不冒充本轮自动验收。
