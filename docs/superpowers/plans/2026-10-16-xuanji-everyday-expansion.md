# X3 日常与陪伴体验全方位扩充计划

> 面向当前工作区内联实施。遵守当前 dirty tree，不使用子代理，不提交、推送、清理或安装手机。

2026-10-16 收口：五项实现与自动门禁完成，准确测试计数、协议迁移、APK 哈希和未执行的人工/设备范围见[交接文档](../handoffs/2026-10-16-everyday-expansion-handoff.md)。

**目标：** 在保留既有日常分类、卡片视觉、离线算法和用户主动控制的基础上，补齐库存/份数/每份预算参考/周菜单、安排冲突处理、通知内完成或延后、软记忆期限管理及可识别的本地构建清单。

**架构：** 复用现有按档案隔离的 `DailyLifeStore`、`SoftMemoryTagStore`、`MysticEvidenceBuilder` 与 Gradle 输出，不复制持久化系统。周菜单是显式安排工具，不把同一天的占卜盘面外推到未来；食材库存只记录名称和用户自填备注，不推断数量或营养。

**技术栈：** Kotlin/JVM domain、DataStore `PreferenceBridge`、Compose Material3、Gradle Kotlin DSL。

- `data/local/DailyLifeStore.kt`：复用档案隔离文档持久化接口。
- `ui/components/DailyLifeActions.kt`：保存推荐到安排时编辑份数。
- `ui/history/DailyLifePanel.kt`：周菜单、库存清单、冲突提示、延期/复制操作、份数编辑、预算估算提示和购物清单状态。
- `domain/SoftMemoryTag.kt`、`data/local/SoftMemoryTagStore.kt`：版本兼容、编辑、有效期和过期语义。
- `ui/components/MysticSoftMemoryPanel.kt` 与 `ui/profile/ProfileScreen.kt`：记忆管理入口和逐条编辑/期限选择。
- `daily/AgendaReminderWorker.kt` 与 Manifest：提醒通知直接标记完成或约一小时后提醒；延后工作按档案/事项去重，并在触发前核对档案和待办状态。
- `app/build.gradle.kts`：后续实际 Debug APK 构建成功后生成包含版本、源码标识、工作树状态、UTC 构建时间和 APK SHA-256 的本地构建清单。
- `README.md`、`SYSTEMS_OVERVIEW.md`、`docs/TECHNICAL_DEBT.md`、最新交接：同步新增规则及未执行的设备/构建验收边界。

## 实施任务

### 任务 1：库存与周餐安排

- 在 `DailyLifeDocument` 增加有版本兼容默认值的库存条目；周菜单是显式安排的周视图/复制操作，不另造预测记录。
- 库存按食材名称及用户备注保存，不把“有库存”解释成库存数量；周菜单只整理用户主动保存的安排，并标明不是未来运势预测。
- 菜单条目支持 1–20 份；只将目录已有的每份参考预算乘份数，并明确是静态估算、非实际花费；未提供估价的旧条目显示“未估算”，食材数量不随份数虚构。
- 购物清单显示库存覆盖状态并保留每道菜来源；不同日期、档案互不污染。

### 任务 2：日程冲突及快捷调整

- 同日同一非空时间的安排视为冲突；保存前展示冲突项并要求用户选择保留、改时间或取消。
- 支持将未完成事项延期到选定日期、复制某日安排到目标日；复制生成新 ID，完成状态重置，备注和菜单份数保留。
- 删除/延期/复制只影响用户明确选择的项目；唯一 WorkManager 日程提醒通知提供完成和约一小时后提醒操作，延后任务使用档案/事项唯一键，并在执行时核对事项仍待办且档案仍匹配。

### 任务 3：可管理的软记忆

- 软记忆协议升到 v2，v1 记录仍可读并按“无期限”迁移。
- 每条标签可修改显示和值、设为无期限或 7/30/90 天后过期；以本地日期判断，到期标签保留在管理页并显示过期，但不作为有效提示展示。
- 在“我的 → 隐私与数据”提供独立管理入口；保留聊天中的简洁摘要与撤回操作。
- 按当前档案读写；编辑、撤回和清除失败时保留旧数据并明确提示。

### 任务 4：本机构建可识别性

- Debug APK 构建成功后生成 `build-manifest.json`，记录 applicationId、variant、versionName/versionCode、源码 HEAD（若不可用则明确标记）、UTC 时间和 APK SHA-256。
- 输出文件留在 Gradle build 目录，不进入源码控制；不改变版本号或签名配置。
- 文档明确本地构建清单描述当前工作区 HEAD，不能代表未提交改动都可由 commit 重现。

- 保留先前对话、占卜来源、游戏及隐私边界；本轮不扩充无来源的营养、价格、气候或占卜结论。
