人物文化差异

A

结构化文化骨架（推荐）

按文化重做衣领、肩线、袖口、头饰和手势：江南交领、学院西装、丝路披肩、沙漠长袍、节庆鼓饰各自有清楚轮廓，不再只是换色。

优点

  • 一眼可辨文化语汇
  • 仍能共享慈翁/魔师脸部骨架

代价

  • 需要重画 8 套服饰路径
B

统一人物 + 文化道具

保留统一长袍，只替换帽冠、乐器、经卷、沙漏、鼓和纹样，减少绘制成本。

优点

  • 上线快

代价

  • 仍可能被感知为换装
C

文化场景舞台

人物保持克制，背景切换为书斋、星盘台、沙漠夜营、鼓乐祭台，用环境讲文化。

优点

  • 氛围最强

代价

  • 遮挡风险和性能成本最高
